# 小睿经纪 UI 设计稿

本仓库提供一版「小睿经纪」房产服务首页的高保真 UI 设计稿，参考用户给出的成品图风格，输出为可直接预览的静态页面与矢量成品图。

## 文件说明

- `index.html`：设计稿预览页，直接在浏览器打开即可查看整体效果。
- `assets/xiaorui-real-estate-ui.svg`：690 × 1180 的矢量 UI 成品图，可放大查看或导入设计工具继续编辑。

## 设计内容

- 顶部绿色品牌区：包含品牌标识、Slogan、城市选择、搜索入口和地图按钮。
- 主视觉卡片：突出「尊享您的品质看房体验」主题，并展示真实房源、专人带看、高效成交三项服务承诺。
- 核心业务入口：新房、二手房、租房、我是房东四个大卡片。
- 常用服务宫格：新房榜、二手房榜、热门楼盘、装修服务、房价走势、房屋评估、找小区、查附近、资讯中心、48h 降价房。
- 内容资讯模块：小睿看点文章卡片。
- 底部导航：推荐分类 Tabs 与 App 主导航。
